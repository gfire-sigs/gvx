# Code of Conduct

This repository is a shared engineering workspace. Every participant in issues, pull requests, code reviews, and security reports is expected to maintain a collegial and factual environment.

## 1. Expected Behavior

Contributors and maintainers uphold these standards in all project spaces:

- Keep technical criticism directed at code, designs, measurements, and evidence rather than at individuals.
- State assumptions, reproduction steps, and limitations plainly so other engineers can verify claims independently.
- Welcome newcomers asking questions about build prerequisites, architecture, or first contributions.
- Respect the time of reviewers by keeping pull requests focused, verified, and clear in scope.

## 2. Unacceptable Behavior

The project does not tolerate personal attacks, harassment, discrimination, intimidation, or deliberate publication of another participant's private information. Public disclosure of an unpatched security vulnerability outside [`SECURITY.md`](SECURITY.md) is likewise prohibited.

## 3. Enforcement

Report conduct violations privately to the repository maintainers through GitHub security or maintainer contact channels listed on the organization profile. Maintainers investigate reports promptly and may issue a warning, edit or remove offending comments, or revoke repository participation privileges when necessary.
