# Pinned `virglrenderer` Patches

These patches apply to the pinned `virglrenderer` checkout (`211ca6e3ac98a2c1`) during `scripts/gpu/build-renderer.sh`. Every patch uses the MIT license of `virglrenderer` and is a candidate for upstream submission.

| Patch | Purpose |
| :--- | :--- |
| `0001-vrend-strip-core-desktop-extensions.patch` | Drops `#extension GL_<name> : require\|enable` lines for features core in the host desktop GLSL version when the host omits those extension strings (Apple OpenGL 4.1 core), and raises the desktop `#version` line to match. |
| `0002-vrend-multisample-without-storage.patch` | Uses `glTexImage2DMultisample` on desktop GL hosts that support `GL_ARB_texture_storage` without `GL_ARB_texture_storage_multisample`, populating `supported_multisample_formats` and guarding multisample texture allocation. |
| `0003-vkr-check-image-and-view-create-info.patch` | Adds tests of the guest create info of images, image views, buffers, and buffer views to `vkr`. The tests run before the host driver gets the create info, because Metal stops the renderer process when a texture descriptor is not valid. `vkr` refuses invalid create info with `VK_ERROR_VALIDATION_FAILED`. The patch also has a workaround for KosmicKrisp (Mesa 26.3), which stops the process on a valid 3D image. A 3D image can have more mip levels than a 2D texture of its width and height. For such an image, `vkr` removes the 2D view flags. `scripts/gpu/gen_vkr_format_table.py` writes the format table of the patch (`src/venus/vkr_format_table.h`) from the Vulkan registry. |
| `0004-vrend-end-transform-feedback-with-program.patch` | Records the linked program at `glBeginTransformFeedback` and binds it before `glEndTransformFeedback`. Ends a transform feedback before `vrend` deletes its program or its transform feedback object. Ends it and starts it again when a draw uses a different linked program. Apple OpenGL 4.1 reads the current program in `glEndTransformFeedback`. With program 0 the renderer process stops (`SIGSEGV`). With a different program the call returns `GL_INVALID_OPERATION`. |
| `0005-vrend-framebuffer-without-surfaces.patch` | Attaches a 1x1 placeholder renderbuffer before a draw or a clear while the guest binds no color surface and no depth surface. Selects the placeholder with `glReadBuffer`, because Apple OpenGL 4.1 reports `GL_FRAMEBUFFER_UNSUPPORTED` when each draw buffer and the read buffer are `GL_NONE`. Applies only to hosts without `GL_ARB_framebuffer_no_attachments`. Without the placeholder the framebuffer is incomplete and each draw returns `GL_INVALID_FRAMEBUFFER_OPERATION`. |
| `0006-vrend-dual-source-fragment-outputs.patch` | Emits only `fsout_c0` and `fsout_c1` for a fragment shader that writes color 0 to all color buffers and also writes the second source color. Apple OpenGL 4.1 refuses the program that has the copies of color 0 ("Exceeded max dual source draw buffers of 1"). |
| `0007-vrend-sole-fragment-output-location.patch` | Binds the location of a fragment shader output when it is the only output and its color index is above 0. Without the binding the linker gives it location 0 and the draw writes the wrong color buffer. |
| `0008-vrend-3d-texture-mipmap-level-check.patch` | Includes the depth of a 3D texture in the mipmap level check of `check_resource_valid`. `vrend` then accepts a legal 3D texture whose depth is its largest dimension. Makes the level limit exact (`util_logbase2` of the largest dimension). |
| `0009-vrend-blitter-core-profile-glsl-version.patch` | Replaces `#version 130` in the blitter shaders with `#version 400` or `#version 150` on a desktop core profile context. Such a context does not accept GLSL 1.30. |
| `0010-vrend-legacy-vertex-integer-attributes.patch` | Enables `use_integer` when `GL_VENDOR` is `"Apple"` and fixes integer vertex attributes on the legacy vertex path (hosts without `GL_ARB_vertex_attrib_binding`). Populates integer sign masks in `vrend_create_vertex_elements_state` and adds `src_offset` for zero-stride constant attributes. Uploads pure integer constants with `glVertexAttribI4iv` or `glVertexAttribI4uiv`, and sets `SHADER_REQ_INTS` for typed integer vertex inputs. |
| `0011-vrend-resource-copy-fallback-bounds.patch` | Fixes `vrend_resource_copy_fallback` size math, bounds checks, and uploads on hosts without `GL_ARB_copy_image`. Computes slice sizes and offsets in 64 bits with `INT_MAX` and `SIZE_MAX` bounds, and drives uploads from `dst_res->target`. |
| `0012-vrend-srgb-blit-before-gl44.patch` | Routes single-sample sRGB color blits on desktop OpenGL below 4.4 to the shader blitter when one format is sRGB. Also routes sRGB-to-sRGB blits with scaling and a linear filter. Keeps multisample sources and targets (`nr_samples > 1`) on `glBlitFramebuffer`, because a shader blit cannot resolve MSAA. |
| `0013-vkr-kosmickrisp-viewport-and-pipeline-cache.patch` | Adds two workarounds for KosmicKrisp (Mesa 26.3) in `vkr`, gated on `VK_DRIVER_ID_MESA_KOSMICKRISP`. Clamps `maxViewportDimensions` to `maxFramebufferWidth` and `maxFramebufferHeight` (16384) in `vkGetPhysicalDeviceProperties` and `vkGetPhysicalDeviceProperties2`. Keeps `viewportBoundsRange` within `[-2 * max_dim, 2 * max_dim - 1]` when `vkr` clamps `maxViewportDimensions`. Passes `VK_NULL_HANDLE` instead of the guest pipeline cache in `vkCreateGraphicsPipelines` when any create info chains `VkRenderingAttachmentLocationInfo`. |
